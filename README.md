# Armour Community Training

A landing page for Armour Training CIC's free community programme in Harrow, supported by The National Lottery Community Fund.

**Live site:** https://armourcommunitytraining.org.uk

## The project

I offered to help my martial arts gym owner refresh his website. That conversation led to a separate page for his community programme: free boxing fitness and conditioning classes for adults, and inclusive boxing and fitness sessions for young people with ADHD, autism and SEND.

## Key decisions

- **A site of its own:** the programme is run by a separate non-profit, so it has its own domain and identity, and the gym's main website stays focused on the gym.
- **Owned by the client:** the domain is registered to Armour Training CIC, using its Companies House details.
- **Calm and readable for a neurodiverse audience:** clear headings, generous spacing, no animation, left-aligned text with limited line length, and colour contrast that meets WCAG AA.
- **Fast-loading images:** the logo is served as WebP in two sizes, so phones download a smaller file, with a PNG fallback for older browsers.

## Built with

HTML, CSS and JavaScript. Hosted on Netlify and deployed from GitHub.

## How it was built

The client supplied the logo and the core wording. I designed everything else: the colour palette, layout, page structure and user interface, adapting to his feedback over several rounds of amendments.

I used Claude Code as a coding assistant. I led the design decisions, client communication and testing.
